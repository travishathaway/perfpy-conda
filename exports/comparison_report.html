Conda Performance Comparison: Conda vs Rattler

This report compares the performance of conda and rattler repodata fetching across different scenarios. We also compare the differences between shared repodata fetching and not sharded repodata fetching.

Test scenarios explained:

  • Datascience: fetching repodata for the packages "pandas", "plotly" and "scipy"
  • Python: fetching repodata for the "python" package
  • Warm: cache is fully loaded with no network requests necessary
  • Cold: cache is empty requiring network requests
